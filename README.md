# Toq de Venus
Experiência digital cinematográfica para deploy no Vercel.

## Instalação
npm install
npm run dev

## Build
npm run build
npm run start

## Mídias
Coloque as fotografias em `public/images` e os vídeos em `public/videos` conforme os nomes usados no projeto.

## Configuração
Edite `lib/siteConfig.ts` para nome, Instagram e WhatsApp. Edite `data/professionals.ts` para os dados reais das profissionais.

Nenhum dado comercial desconhecido foi inventado. Serviços e contatos estão como configuração provisória.

## Deploy
Suba o projeto ao GitHub e importe o repositório na Vercel. O projeto não depende de backend.
